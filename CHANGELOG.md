# Changelog

All notable user-visible changes to **fast-java-skill** are documented here.

## [0.1.0] - 2026-08-29

### Added

- Initial Agent Skill entrypoint with trigger-only YAML frontmatter.
- Project reconstruction workflow for vague, partial, or resume-level project descriptions.
- Java Backend deep-dive reference covering runtime, Spring, databases, Redis, messaging, Elasticsearch, idempotency, and scale.
- RAG / Agent reference covering ingestion, chunking, embeddings, hybrid retrieval, reranking, evaluation, routing, state/checkpoints, Tool safety, and Agent failure modes.
- Parameter baseline reference with explicit tuning and validation rules.
- Interview Red Team protocol with 3–6 layer follow-up chains and answer grading.
- Sports-commerce RAG worked example.
- Pressure evaluation scenarios for common Skill regressions.
- Maintainer and contribution guides.

### Design principles

- Progressive disclosure instead of one giant prompt.
- Engineering depth over buzzwords.
- Parameter baselines must be measurable and revisable.
- Complex technologies must justify their existence.
- No fabricated personal production evidence.
